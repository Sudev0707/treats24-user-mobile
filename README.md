
# treats24

A modern food delivery mobile application built with React Native, designed to connect users with their favorite restaurants and deliver delicious meals right to their doorstep.


## Features

- **User Authentication**: Secure login via phone OTP or email verification
- **Restaurant Discovery**: Browse top restaurants and explore food categories
- **Real-time Cart Management**: Add, remove, and modify items with instant updates
- **Location Services**: Set delivery locations and find nearby restaurants
- **Deals & Offers**: Access exclusive deals and promotional offers
- **Order Tracking**: Seamless checkout process with payment integration
- **Offline Support**: Local database for persistent data storage

## Tech Stack

- **Framework**: React Native CLI
- **Navigation**: React Navigation (Stack & Tab navigators)
- **State Management**: Redux Toolkit
- **Authentication**: Firebase Auth
- **Database**: SQLite for local storage
- **API**: Axios for HTTP requests
- **UI Components**: Custom components with React Native Vector Icons
